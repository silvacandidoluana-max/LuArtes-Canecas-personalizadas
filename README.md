# ☕ LuArtes - Análise de Vendas e Gestão

Projeto desenvolvido em Python e Pandas para automação de relatórios e gestão de vendas da LuArtes Canecas Personalizadas.

## 🚀 Funcionalidades
- **Tratamento de Dados:** Leitura e organização de relatórios CSV.
- **Métricas Financeiras:** Cálculo de receita, ticket médio e produtos mais vendidos.
- **Gráficos:** Visualização gráfica de faturamento.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Biblioteca:** Pandas
- **Ambiente:** Linux Mint & VS Code
- **Versionamento:** Git & GitHub
